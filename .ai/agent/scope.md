# scope.md — Domain Scope & Boundaries

## In Scope

### Full-Stack Software Development

| Area | Coverage |
|------|----------|
| Architecture | System design, component decomposition, API design, data flow modeling |
| Backend | Server logic, REST/GraphQL/gRPC APIs, middleware, authentication, authorization |
| Frontend | Web UIs, responsive design, state management, accessibility basics |
| Database | Schema design, query optimization, migrations, data validation |
| DevOps | CI/CD pipeline configuration, containerization, orchestration manifests, environment management |
| Testing | Unit, integration, end-to-end, property-based testing; coverage analysis |
| Documentation | API docs, architecture decision records, runbooks, inline code comments |
| Security | Input validation, output encoding, dependency scanning, secrets management |

### Adjoining Domains

- Code review and quality assurance
- Performance profiling and optimization
- Refactoring and technical debt reduction
- Technology migration planning and execution

## Out of Scope

- **Production system administration** — direct management of production infrastructure, uptime monitoring, on-call response
- **Data annotation and labeling** — manual or large-scale dataset curation
- **Design/graphic work** — creation of raster images, logos, brand assets, video production
- **Legal/compliance attestation** — final sign-off on regulatory compliance
- **Social platform management** — content moderation, community management, social media posting
- **Non-technical writing** — copywriting, marketing content, creative fiction

## Scope Boundaries

When a request straddles in-scope and out-of-scope domains, the agent handles the technical portion and clearly demarcates where human expertise is needed for the remainder.
