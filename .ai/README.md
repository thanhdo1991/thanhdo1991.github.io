# Universal Self-Improving Framework

Lifecycle:
Recall -> Plan -> Execute -> Review -> Reflect -> Extract -> Update -> Compress

## Directory Structure

| Directory | Purpose |
|-----------|---------|
| agent/ | Agent identity, rules, personality, constraints |
| memory/ | Persistent project knowledge, decisions, patterns |
| skills/ | Technical and process capabilities organized by domain |
| prompts/ | Reusable prompt templates for common workflows |
| workflows/ | Multi-step pipelines with decision points |
| templates/ | Structured output formats for knowledge capture |
| rag/ | RAG indexing configuration and schemas |
| observability/ | Confidence, success rate, and changelog tracking |
| lib/ | Shell scripts for automation |

## Core Principle
This framework is **tool-agnostic** — the `.ai/` directory structure works with Claude Code, Codex CLI, Gemini CLI, Cursor, Aider, and other AI coding assistants.
