## Key Principles
1. **Separation of concerns** — Each component has one clear responsibility
2. **Interface-first** — Define contracts before implementation
3. **YAGNI** — Build only what's needed, not what might be needed
4. **Design for change** — Anticipate evolution without over-engineering
